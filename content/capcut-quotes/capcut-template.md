## วิธีบันทึกเป็นเทมเพลตใน CapCut

1. สร้างตอนที่ 1 ให้เสร็จตามโครงด้านบน
2. ตั้งชื่อเลเยอร์ข้อความให้ชัด เช่น `HOOK`, `QUOTE`, `EXPLAIN_1`, `EXPLAIN_2`, `SUMMARY`, `CTA`
3. บนเดสก์ท็อป: เปิดโปรเจกต์แล้ว Duplicate ทุกครั้งที่ทำตอนใหม่ จากนั้นแทนคลิปและแก้ข้อความ
4. ถ้าบัญชีมีสิทธิ์ Template Creator: กด Export as template แล้วเลือกให้คลิปและข้อความเป็นช่องที่แก้ไขได้ (replaceable) เพื่อขายหรือแจกเทมเพลตได้
5. บันทึกสไตล์ข้อความแต่ละแบบเป็น Text Preset เพื่อให้ทุกตอนหน้าตาเหมือนกัน

## ขั้นตอนผลิตแต่ละตอน

1. ก็อป prompt ภาพนิ่งของตอนนั้นไปใช้ใน ChatGPT แล้วดาวน์โหลดภาพแนวตั้ง
2. ก็อป prompt วิดีโอไปใช้ใน Flow สร้างคลิป 3 ฉาก ฉากละประมาณ 8 วินาที
3. อัดเสียงพากย์จากสคริปต์ หรือใช้ Text to Speech
4. เปิดเทมเพลตใน CapCut แทนคลิป แทนข้อความ ใส่เสียง
5. ตรวจซับไตเติล ตรวจว่าข้อความไม่ถูกปุ่มของแพลตฟอร์มบัง แล้ว Export 1080p
